# Eduardo-Oliveira-Desenvolvimento-e-automacao

Portfólio de Eduardo Oliveira em Next.js: crachá 3D interativo, projetos, contato e comentários com anexos.

Use Node.js 24, npm ci e npm run dev. Para produção, npm run build. Na Vercel, conecte um Vercel Blob **privado** ao projeto (BLOB_READ_WRITE_TOKEN apenas no servidor). Mensagens ficam em messages/, imagens em media/ e comentários em data/. Escritas concorrentes usam ETags e leituras sem cache. O armazenamento inicia vazio, separado da prévia Sites. Não há envio automático de e-mail. Configure currículo e certificados em app/data.ts.
